# JAMB Prep CBT — PWA installation

This build includes:
- Web App Manifest with 192x192 and 512x512 icons
- Service worker registration
- Android/Chrome install prompt using `beforeinstallprompt`
- iPhone/iPad Add to Home Screen guidance
- Standalone app display mode

Deploy the `site` directory as the website root. The site must be served over HTTPS (localhost is also valid for testing).
